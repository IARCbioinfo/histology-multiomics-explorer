# Explorer MCP server

Read-only MCP server for the Tumour Histology and Multi-omics Explorer. Run it from GitHub with `uvx --from "git+https://github.com/IARCbioinfo/histology-multiomics-explorer#subdirectory=mcp" histology-multiomics-explorer-mcp`; see the repository README and https://iarcbioinfo.github.io/histology-multiomics-explorer/agents.html for setup.
